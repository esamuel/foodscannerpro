## Image Requirements
- Resolution: 1024x1024 pixels (will be scaled down as needed)
- Format: JPEG or PNG
- Quality: High quality, appetizing food photography
- Style: Consistent lighting and styling across all images
- Background: Light, neutral backgrounds preferred
- Composition: Food should be clearly visible and identifiable

## Adding Images
1. Create a new image set in `Assets.xcassets/RecommendationImages` for each image
2. Add 1x, 2x, and 3x versions if available
3. Set the image set properties:
   - Render As: Default
   - Scales: Single Scale
   - Devices: Universal
   - Color Profile: sRGB
